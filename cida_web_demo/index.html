SDK & API Integration

Interact with CIDA through simple Python wrappers or OpenAI-compatible endpoints.

Initialize a locally deployable continuous latent reasoning model on CPU/GPU:

# Import CIDA-plugin and wrap any local PyTorch model
from cida_plugin.inference import LatentAgent, HuggingFaceBackbone
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen1.5-7B-Chat")
llm = AutoModelForCausalLM.from_pretrained("Qwen/Qwen1.5-7B-Chat", device_map="auto")

agent = LatentAgent(
    d_model=4096,
    llm=llm,
    tokenizer=tokenizer,
    default_reasoning_rounds=3
)

response = agent.run("If A is older than B, B is older than C... Is C older than A?")
print(response)

Simply point any existing OpenAI-SDK script to the CIDA middleware gateway:

import openai

openai.api_key = "dummy-key"
openai.base_url = "http://localhost:8000/v1"

response = openai.chat.completions.create(
    model="kairos-cida-v1.5",
    messages=[
        {"role": "user", "content": "Explain the Monty Hall dilemma and why I should switch doors."}
    ],
    temperature=0.2
)

print(response.choices[0].message.content)

Leverage the new dynamic middleware swap to intercept prompts and hot-swap adapters in real-time:

from cida_gateway import CIDAMiddleware

# Initialize with a base model
model = CIDAMiddleware(base_model="Qwen/Qwen1.5-7B-Chat")

# Register small task-specific cognitive adapters
model.register_adapter("math", "kirtzh/CIDA-Math-v1")
model.register_adapter("logic", "kirtzh/CIDA-Logic-v1")

# Route and dynamically hot-swap adapter weights in <10ms
response = model.generate(
    prompt="If all humans are mortal, and Socrates is human...",
    task_type="logic"
)

Lab Philosophy

Our mission and values at VEIMO Research Lab.

Latent Coordination

Rather than passing thousands of text tokens back and forth between agents, we route dense hidden representations, cutting token cost by over 80%.

Zero-Latency Safety

Assess security, rules, and alignment in the latent space before generating text, avoiding the double-inference overhead of traditional guardrails.

Plug & Play Adaptability

Build highly specialized logical reasoning models as lightweight vector adapters that can be dynamically loaded and swapped on the fly.
