# 🚀 Roadmap: Kairos-CIDA 1B Scaling & Paradigm Shift

Этот документ фиксирует стратегическое видение и технический план перехода от легковесного плагина оптимизации к **Фундаментальному Когнитивному Сопроцессору (Cognitive Co-Processor)** с миллиардом параметров.

---

## 1. Концептуальный Сдвиг (От Знаний к Процессу)
Текущие LLM (даже GPT-4) обучаются как гигантские базы данных — они запоминают факты, но часто проваливаются в строгой многошаговой логике. 

**Новая парадигма CIDA:** CIDA не должна учить факты (что Париж — столица Франции). Этим занимается базовая LLM (Backbone). CIDA должна обучаться **чистому алгоритмическому поиску и структурированию знаний**. 
Как ребенок, который уже выучил алфавит (LLM), но теперь должен научиться писать из него связные романы (CIDA).

---

## 2. Решение проблемы вычислений: Offline Latent Training
**Проблема:** Прикрепление CIDA на 1B параметров к «самой умной» LLM (например, LLaMA-3.1 70B) сделает обучение невозможным. Видеопамять (VRAM) переполнится, а каждый шаг градиентного спуска будет занимать минуты из-за гигантского бэкбона.

**Решение (Офлайн-кэширование):**
Мы полностью отвязываем процесс обучения CIDA от генерации LLM.
1. **Этап 1 (Кэширование):** Прогоняем весь обучающий датасет через замороженную LLaMA-3 70B только в режиме Forward-pass (без градиентов).
2. **Этап 2 (Сохранение):** Извлекаем только последнее скрытое состояние (например, вектор размерностью 8192) для каждого промпта и сохраняем на жесткий диск как `.pt` или `.safetensors`.
3. **Этап 3 (Изолированное обучение):** Выгружаем 70B модель из памяти. Загружаем 1B CIDA и обучаем её *только* на сохраненных векторах с диска. 
   - *Эффект:* Скорость обучения возрастает в 1000+ раз. Обучение миллиардной архитектуры становится доступным на потребительских GPU.
4. **Этап 4 (Сборка):** На инференсе соединяем обученную CIDA обратно с 70B моделью.

---

## 3. Революция Датасетов: PRM и Деревья Поиска
Мы больше не обучаем модель банальным примерам «Вопрос -> Правильный ответ» (как в GSM8K). Это учит модель быть «попугаем». Мы учим её мыслить.

**Новые подходы к формированию данных:**
* **Синтетический Backtracking (Откаты):** В датасете должны быть примеры, где рассуждение заходит в тупик. CIDA должна учить паттерн: *«Выдвижение гипотезы -> Проверка -> Обнаружение противоречия -> Откат на шаг назад (Rollback) -> Новый путь»*.
* **Process Reward Models (PRM):** Алгоритм обучения с подкреплением (RL). CIDA получает награду не за правильный финальный ответ, а за **каждый логически верный шаг**. Это заставляет агентов внутри CIDA строго соблюдать законы математики и логики на микроуровне.
* **MCTS в Латентном Пространстве (Monte Carlo Tree Search):** Вместо текстовой генерации "Chain-of-Thought", агенты CIDA разворачивают граф поиска вариантов внутри векторов (сравнивая вероятности успеха разных логических путей).

---

## 4. Архитектура Когнитивного Сопроцессора
```text
[ Текстовый Промпт ]
       |
( LLM: Парсинг синтаксиса и извлечение фактов )
       |
[ Вектор 8192d ] ====> [ Входной Проектор ]
                            |
                     [ CIDA Core 1B ]  <--- Здесь происходят глубокие MCTS дебаты
                            |
[ 8 Токенов-Планов ] <== [ Выходной Проектор ]
       |
( LLM: Генерация идеального текстового ответа )
```
*Если завтра выходит новая LLM (LLaMA-4), ядро CIDA 1B не нужно переобучать! Обучаются только легкие проекторы входа и выхода (занимает пару часов).*
