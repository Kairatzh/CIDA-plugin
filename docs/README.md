## 🚀 С чего начать?

- **Вы новый член команды?** → Начните с `1_CIDA_Vision_For_Everyone.md`, потом `2_CIDA_Project_Wiki_and_Glossary.md`
- **Вы разработчик?** → Сразу к `5_CIDA_Developer_Quickstart.md`
- **Вы готовите презентацию?** → `6_CIDA_Pitch_Deck_Outline.md`
- **Вам нужны технические детали?** → `3_CIDA_Architecture_and_Chronology.md`
- **Готовите релиз?** → `4_CIDA_Release_Playbook.md`
