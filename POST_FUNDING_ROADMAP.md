# Пост-Инвестиционный Архитектурный План (CIDA 2.0)

Этот документ содержит ключевые архитектурные идеи, которые будут реализованы **после получения финансирования** (Seed/Series A) для масштабирования проекта до уровня Foundation Model.

## 1. Несжатый Мост и RLCF (Latent Alignment)
**Проблема:** При сжатии сложного логического вывода в один вектор (bottleneck) для базовой LLM, её языковая модель ломается (деградация генерации текста).
**Решение:**
- Переход от выдачи одного вектора к генерации **последовательности "Soft-токенов"** (например, 8-16 векторов).
- Внедрение **RLCF (Reinforcement Learning from CIDA Feedback)**: Обучение моста (LatentSemanticTranslator) с помощью RL, где LLM получает награду за генерацию грамматически чистого текста без потери изначального логического смысла, заложенного CIDA. 
- LLM будет воспринимать латентные векторы CIDA не как инородный шум, а как понятный внутренний концепт.

## 2. Память и Контекст (Multi-turn State)
**Проблема:** CIDA работает без сохранения состояния (stateless), что не позволяет вести долгие диалоги с сохранением "System 2" контекста.
**Решение:**
- Внедрение **Токена Памяти (`[MEM]`)**. На каждом шаге генерации CIDA формирует специальный латентный токен, который передается самому себе на следующем ходу.
- Альтернатива: Интеграция легкого State Space Model (Mamba) внутрь ядра CIDA для бесконечного контекста.

## 3. Кросс-платформенность (MoE Independence)
**Подтвержденная парадигма:**
CIDA работает на уровне скрытых состояний (Hidden States) и эмбеддингов, что делает её полностью независимой от внутренних механизмов LLM (будь то стандартный Трансформер или Mixture of Experts). Это позволяет продавать CIDA как универсальный "plug-and-play" чип логики для любых будущих open-source моделей.
